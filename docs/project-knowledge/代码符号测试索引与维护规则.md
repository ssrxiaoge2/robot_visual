## 4. 新增缺料信号模块的影响清单

新增真实缺料信号时，至少检查：

- 信号来源、连接生命周期、断线重连和消息确认；
- 工位号映射与非法值处理；
- 重复消息的业务含义，是独立缺料还是需要幂等；
- 去抖窗口、事件有效期和时间戳；
- 是否需要扩展 `TaskSource`；
- 进入 `LineManager::reportShortage` 前是否已完成协议归一化；
- 主调度处于 `Idle`、`Running`、`ReturningHome`、`Error` 时的行为；
- 当前任务与同工位 Pending 同时存在时的行为；
- 充电派单保持期间只入队、不启动；
- 自动充电安全结束后是否正确恢复派单；
- UI 是否显示信号连接、最后事件和拒绝原因；
- 日志是否包含来源、工位和可追踪事件标识；
- 正常、重复、乱序、断线重发、非法工位和充电互斥测试。

## 5. 文档维护策略

采用“开发过程中记录，提交前统一更新”：

涉及调度、机械臂、视觉、AGV、扫码、码垛、充电或外部接口时，必须使用仓库级项目 Skill `robot-visual-doc-sync`。该 Skill 位于 `.agents/skills/robot-visual-doc-sync`，负责差异映射、最小阅读范围和提交前一致性检查。

新增任何功能或核心源码模块时也必须使用该 Skill。尚未登记的 `src` 源码由脚本保守映射到项目入口、系统架构、符号测试索引和业务不变量；首次功能提交必须再为新模块增加精确路径映射和单元测试，并更新实际受影响的专题文档。

### 5.1 开发过程中

- 在任务说明、工作笔记或提交草稿中记录影响的模块、状态、接口和测试。
- 不要求每次局部编辑都修改正式架构文档。
- 代码尚未稳定时，不反复重画正式流程图。

### 5.2 提交前

当最终代码稳定后，根据真实实现一次性更新本目录相关文档，并检查 Mermaid 图、类名、状态名、信号名和测试文件仍然存在。

正式项目文档的更新时间点是“代码逻辑已经稳定、执行最终验证之前”。顺序固定为：

1. 完成代码和测试修改。
2. 运行相关测试，确认最终行为已经稳定。
3. 根据实际差异更新本目录中的正式项目文档。
4. 检查文档中的类名、状态、信号、流程和测试入口。
5. 再执行提交前完整验证。
6. 代码、测试和对应文档放在同一个提交中。

最终提交前执行：

```powershell
python .agents/skills/robot-visual-doc-sync/scripts/check_doc_sync.py --staged --check
```

禁止在代码逻辑已改变但正式文档尚未同步时创建最终功能提交。若一次开发需要多个中间提交，中间提交不得宣称功能完成；最终功能提交前必须完成文档同步。

以下变化必须更新正式文档：

1. 新增、删除或改变调度器、控制器、协调器的职责。
2. 改变跨模块调用、Qt 信号槽、线程或对象所有权。
3. 改变任务顺序、状态切换、超时、失败恢复或安全条件。
4. 新增外部信号、协议字段、设备接口或持久化配置。
5. 改变生产主线与自动充电、旧流程之间的互斥关系。
6. 改变机械臂动作顺序、SDK 参数、视觉目标判断、坐标变换或运动完成证据。
7. 改变日志追踪方式、现场恢复步骤或故障分级。
8. 改变外部字段、寄存器、单位、缩放、枚举或数据有效条件。
9. 改变《关键业务不变量与现场约束》中的任一安全底线。

以下变化通常不需要更新总架构：

- 文案、颜色和不改变业务语义的 UI 布局；
- 局部日志格式；
- 不改变调用契约的内部算法优化；
- 测试代码的机械性整理。

## 6. 提交前认知一致性检查

- [ ] 项目认知入口能把本次问题路由到正确文件。
- [ ] 架构图中的类和所有权与代码一致。
- [ ] 调度时序与真实信号链一致。
- [ ] 新增状态、超时和错误恢复已进入安全约束。
- [ ] 新增核心类已进入符号索引。
- [ ] 新增测试已进入测试路由。
- [ ] 外部数据语义变化已更新数据字典。
- [ ] 现场故障或恢复行为变化已更新排查手册。
- [ ] 核心行为变化没有违反业务不变量，或已明确更新相关约束与测试。
- [ ] 历史设计文档没有被误写成当前事实。
- [ ] 本目录是长期维护的当前事实文档，文件名不带日期；历史设计、计划和报告仍按各自规则使用日期。

## 7. 智能体读取约束

处理局部任务时：

1. 先阅读项目认知入口中的对应路由。
2. 只读取相关核心类、直接连接点和相关测试。
3. 只有发现跨模块影响时，才逐层扩大搜索范围。
4. 不默认读取 `3rd`、构建目录、日志目录和全部历史设计文档。
5. 完成跨模块改动后，在提交前执行第 6 节检查。
