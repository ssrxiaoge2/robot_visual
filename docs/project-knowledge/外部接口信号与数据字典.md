# 外部接口、信号与数据字典

> 本文记录跨系统数据的来源、单位、有效条件、使用者和失效行为。代码字段和现场协议不一致时，先停止联调并核对协议，不能仅修改文档掩盖差异。

## 1. 数据有效性的共同原则

- 单个字段读取成功不代表一轮业务快照有效。
- 异步请求必须校验请求身份、代次或当前状态。
- 写命令响应只证明通信层收到响应，不证明物理动作完成。
- 用于安全决策的值必须有明确来源、单位、时间和失效条件。
- 错误或超时后的占位值不得参与安全判断。

## 2. 缺料事件和任务模型

当前生产入口是 `LineManager::reportShortage(int stationId)`。

| 数据 | 类型或范围 | 当前来源 | 业务语义 |
|---|---|---|---|
| `stationId` | 1～12 | UI 模拟 | 客户业务工位号 |
| `taskId` | 进程内递增无符号整数 | `TaskQueue` | 单次任务追踪标识 |
| `source` | `UiMock`、`CustomerSystem` | 当前固定为 `UiMock` | 缺料任务来源 |
| `createdAt` | UTC 时间 | 入队时生成 | 任务创建时间 |
| `state` | `TaskState` | 队列和执行器 | 任务生命周期 |
| `step` | `TaskStep` | 执行器 | 面向 UI 和日志的业务步骤 |

当前事实：

- 每次合法调用都创建独立任务，同一工位不自动去重。
- `Error` 状态拒绝新缺料。
- `Idle` 状态允许入队但不执行。
- 客户系统自动生成缺料任务的规则尚未实现。

未来缺料信号模块必须明确：

- 外部事件唯一标识；
- 重发是否代表同一事件；
- 去抖和幂等规则；
- 事件有效期；
- 工位字段到 `stationId` 的映射；
- 接收确认和失败重试；
- 何时设置 `TaskSource::CustomerSystem`。

## 3. 客户系统 REST 数据

当前 `CustomSysScheduler` 只访问日数据接口并解析：

| 字段 | 类型 | 当前用途 |
|---|---|---|
| `id` | 64 位整数 | 现场排查 |
| `statDate` | 日期时间 | 现场排查 |
| `lineId` | 字符串 | 产线标识 |
| `lineName` | 字符串 | 产线名称 |
| `planQty` | 整数 | 计划数量 |
| `actualQty` | 整数 | 当前业务读取值 |
| `okQty` | 整数 | 合格数量 |
| `ngQty` | 整数 | 不合格数量 |

当前接口只提供连通性、GET 请求和 JSON 解析，不会自动调用 `reportShortage()`。

## 4. AGV Modbus 数据

文档地址是 1 基，发送 Modbus PDU 时由 `AgvController::pdu()` 减一。

### 4.1 写入和控制

| 文档地址 | 类型 | 业务含义 |
|---|---|---|
| `[4x]00001` | 保持寄存器 | 写目标站点，触发导航 |
| `[0x]00004` | 线圈 | 暂停导航 |
| `[0x]00005` | 线圈 | 继续导航 |
| `[0x]00006` | 线圈 | 取消导航 |
| `[0x]00020` | 线圈 | 写 1 请求 DO0 低电平 |
| `[0x]00060` | 线圈 | 写 1 请求 DO0 高电平 |

### 4.2 监控快照

| 字段 | 文档地址 | 范围或单位 | 使用者 | 有效条件 |
|---|---|---|---|---|
| `navStation` | `[3x]00007` | LM | 任务导航和返航 | 完整快照 |
| `locStatus` | `[3x]00008` | 0失败、1正确、2重定位、3完成 | 现场诊断 | 完整快照 |
| `navStatus` | `[3x]00009` | 0～7 | 调度与充电 | 完整快照 |
| `battery` | `[3x]00013` | 0～100% | 自动充电 | 完整且未过期 |
| `curStation` | `[3x]00034` | LM | 严格到站和充电位置 | 完整快照 |
| `ctrlSeized` | `[3x]00043` | 布尔 | 控制权诊断 | 完整快照 |

`monitorUpdated` 只有在两段寄存器都读取成功后才发布，因此各字段属于同一轮。

### 4.3 导航状态

| 数值 | 枚举 | 业务语义 |
|---|---|---|
| 0 | `None` | 无导航任务 |
| 1 | `Waiting` | 等待执行 |
| 2 | `Running` | 正在导航 |
| 3 | `Paused` | 已暂停 |
| 4 | `Arrived` | 已到达 |
| 5 | `Failed` | 失败 |
| 6 | `Canceled` | 已取消 |
| 7 | `Timeout` | 超时 |

自动充电只把 `None` 或 `Arrived` 视为可接受的导航空闲候选，并且必须同时满足 `curStation=LM1`。

### 4.4 DO0

| 数据 | 地址 | 语义 |
|---|---|---|
| DO0 实际状态 | `[1x]00060` | 只读的最终物理电平证据 |
| `do0EnsureFinished.confirmed` | 布尔 | 是否明确读到目标电平 |
| `actualHigh` | 布尔 | 仅当 `confirmed=true` 时可用于安全判断 |

写回显不能证明最终电平。每轮最多写一次，之后只读确认最多三次，相邻读取间隔 500 ms。

## 5. 视觉 HTTP 数据

### 5.1 接口

| 路径 | 用途 |
|---|---|
| `GET /status` | 服务和相机运行状态 |
| `GET /inference` | 目标候选和抓取数据 |
| `GET /frame/annotated` | 界面标注图像 |

### 5.2 推理根字段

| 数据 | 单位 | 有效条件 | 用途 |
|---|---|---|---|
| `frame_id` | 递增帧号 | 存在且相对基线严格递增 | 排除缓存帧 |
| `timestamp` | 转换为毫秒 | 存在且相对基线严格递增 | 排除缓存或乱序 |
| `objects` | 数组 | JSON 合法 | 候选目标集合 |

### 5.3 目标候选

| 数据 | 单位 | 说明 |
|---|---|---|
| `offset_mm.x` | mm | 视觉原始 X |
| `offset_mm.y` | mm | 视觉原始 Y |
| `depth_compensated` | mm | 深度，越小通常表示层越高 |
| 目标角度 | ° | 转换为工具系 Rz |
| 置信度 | 无量纲 | 当前记录用于诊断，未作为新增阈值过滤 |

候选经手眼矩阵转换为工具系 X/Y/Z，经角度归一化得到 Rz。阶段一使用锚点和锁定上下文限制目标切换。

### 5.4 结果信号

| 信号 | 语义 | 上层行为 |
|---|---|---|
| `rawCoordinatesReady` | 有可信目标和工具系数据 | 进入初始运动或对准判断 |
| `noObjectDetected` | 没有可选目标 | 初始阶段可搜索，验证阶段失败 |
| `targetRejectedByTrustRule` | 有目标但违反信任规则 | 禁止使用旧坐标 |
| `errorOccurred` | 网络或解析错误 | 当前阶段失败或停止 |

每次推理携带生成号和选择上下文。旧回复即使到达，也不能更新最近帧或发出当前任务结果。

## 6. 华沿机械臂 SDK 数据

| 数据 | 单位或范围 | 业务含义 |
|---|---|---|
| TCP X/Y/Z | mm | Base 或指定 UCS 下的实际位置 |
| TCP Rx/Ry/Rz | ° | 实际姿态 |
| 关节 J1～J6 | ° | 当前实际关节位置；首次视觉 MoveJ 中作为逆解参考 |
| moving | 状态值 | 当前是否运动 |
| pause | 状态值 | 是否暂停 |
| FSM 文本 | 字符串 | 自动、待机、就绪、空闲或阻塞状态 |
| blending | 状态 | 运动融合完成证据之一 |
| SDK 返回值 | 0 或错误码 | 0 只表示接口接受，不表示物理到位 |

视觉到工具系修正关系：X 同向，Y 和 Rz 反向。详细运动和完成判断见《华沿机械臂视觉抓取与运动判断》。

## 7. 扫码数据

`NScanScheduler::ScanOptions`：

| 字段 | 默认值 | 语义 |
|---|---:|---|
| `ip` | 由配置注入 | 扫码器地址 |
| `port` | 30000 | 扫码服务端口 |
| `timeoutMs` | 2000 ms | 单次尝试超时 |
| `maxAttempts` | 3 | 最大尝试次数 |
| `retryIntervalMs` | 500 ms | 重试间隔 |
| `triggerCommand` | 单字节 `0x41` | 触发一次扫码 |

`ScanResult` 保存状态、清理后的条码 `code`、原始字节 `rawData`、错误 `errorMessage` 和实际尝试次数 `attempts`。状态包括成功、超时、连接错误、发送错误、读取错误、配置无效和 SDK 不可用。只有 `isSuccess()` 为真时条码才能进入业务比较。

## 8. 充电桩数据

### 8.1 权威快照

一次权威 `ChargePileSnapshot` 必须完成五组顺序读取：

| 字段 | 单位或内容 | 安全用途 |
|---|---|---|
| `outputVoltageV` | V | 输出诊断 |
| `outputCurrentA` | A | 充电开始和停止判断 |
| `inputWord` | 16 位状态字 | 干接点、红外、伸出、缩回、无线 |
| `outputWord` | 16 位状态字 | 等待、故障、充满、工作、风扇、继电器 |
| `eventWord` | 16 位事件字 | 事件诊断，不自动等同阻断故障 |
| `faultWord` | E1～E16 | 故障判断 |
| `sampledAt` | 时间 | 快照完整性和新鲜度 |

`retracted=true`、`working=false`、`relayOn=false` 和安全电流共同构成安全终态证据的一部分。

### 8.2 协议地址

| 地址 | 类型 | 含义 |
|---|---|---|
| `0x0000` | 寄存器 | 实时输出电压 |
| `0x0001` | 寄存器 | 实时输出电流 |
| `0x000C` | 寄存器 | 输入状态字 |
| `0x000D` | 寄存器 | 输出状态字 |
| `0x0011` | 寄存器 | 事件字 |
| `0x0013` | 寄存器 | 故障字 |
| `0x0017` | 寄存器 | 目标电压 |
| `0x0018` | 寄存器 | 目标电流 |
| `0x001A` | 寄存器 | 截止电流 |
| `0x001F` | 寄存器 | 最大充电时长 |
| `0x0003` | 线圈 | 启动 |
| `0x0006` | 线圈 | 停止 |
| `0x0001` | 线圈 | 缩回 |
| `0x0007` | 线圈 | 复位 |

### 8.3 会话身份

- `Manual`：人工调试入口。
- `Automatic`：自动充电协调器拥有的会话。

会话来源必须原样传递到最终完成信号。手动会话不得释放自动派单保持。

## 9. 数据变更检查

修改任何外部字段、地址、单位、缩放、状态枚举或有效条件时：

1. 更新协议解析和领域模型测试。
2. 更新本文。
3. 检查日志是否能显示新字段。
4. 检查旧配置和旧设备版本兼容性。
5. 检查失效值是否仍然按保守策略处理。
