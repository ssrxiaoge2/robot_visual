# v0.3.0 版本元数据更新设计

## 目标

将项目权威版本号从当前滞后的 `0.2.4` 更新为 `0.3.0`，并在变更记录顶部补充本次运行参数设置与视觉深度自动下探功能。

## 修改范围

- `CMakeLists.txt`：将 `project(... VERSION ...)` 更新为 `0.3.0`，继续由现有构建定义注入 `APP_VERSION`。
- `changelog/CHANGELOG.md`：在历史记录之前增加 `2026-07-23 | v0.3.0` 条目。

## 记录内容

发布记录覆盖分类设置窗口、INI 原子持久化、417/380 mm 抓取余量、1200/200/400 mm 深度自动下探策略、运行锁定、事务应用和自动化验证结果。

历史版本条目不修改；用户原有未提交文件不纳入提交。

## 验证

- 检查所有权威版本引用为 `0.3.0`。
- 重新配置 CMake，确认生成的 `APP_VERSION` 来源正确。
- 运行完整构建及 CTest。
