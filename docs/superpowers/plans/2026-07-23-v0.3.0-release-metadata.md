# v0.3.0 版本元数据更新实施计划

> **面向 AI 代理的工作者：** 必需子技能：使用 executing-plans 逐任务实施本计划。

**目标：** 将项目版本统一更新为 v0.3.0，并为本次运行参数设置与视觉深度自动下探功能补充完整的发布记录。

**架构：** 仅修改项目级 CMake 版本元数据和现有 Markdown changelog，不改动运行时代码。完成文本一致性检查后，重新配置、构建并执行完整测试套件。

**技术栈：** CMake、Markdown、Git、MSVC、CTest

---

### 任务 1：更新并验证 v0.3.0 发布元数据

**文件：**

- 修改：`CMakeLists.txt`
- 修改：`changelog/CHANGELOG.md`

**步骤 1：更新项目版本**

将 `project(wh-robot-visual VERSION ...)` 更新为 `0.3.0`。

**步骤 2：添加 changelog**

在 changelog 顶部添加 `2026-07-23 | v0.3.0` 条目，记录：

- 分类运行参数设置界面及运行期只读保护；
- INI 原子持久化、应用失败回滚和分类恢复默认值；
- 大筐与紫筐抓取 Z 余量运行时配置；
- 视觉深度超过 1200 mm 时每次自动下探 200 mm、累计最多 400 mm 并重新检测；
- 调度、视觉和生产流程统一读取运行时配置；
- 本地构建与自动化测试结果，以及实机现场验证仍需执行。

**步骤 3：检查版本引用**

运行：

`rg -n "VERSION 0\.3\.0|v0\.3\.0" CMakeLists.txt changelog/CHANGELOG.md`

预期：CMake 项目版本和 changelog 新条目均为 v0.3.0。

**步骤 4：重新配置并构建**

使用 MSVC Release 配置重新运行 CMake 配置与完整构建。

预期：配置和构建成功。

**步骤 5：运行完整测试**

配置 Qt 运行时环境后执行 Release CTest。

预期：16/16 测试通过。

**步骤 6：检查并提交**

运行 `git diff --check`，仅暂存本计划、`CMakeLists.txt` 和 `changelog/CHANGELOG.md` 的相关提交，保留工作区中的其他用户改动。
