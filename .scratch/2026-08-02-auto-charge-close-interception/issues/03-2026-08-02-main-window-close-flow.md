# 03 - 关闭窗口流程改用专用拦截判断

**What to build:** 关闭窗口流程使用设备管理层提供的关闭窗口专用判断，不再把窗口关闭直接等同于充电控制器通用停机判断。用户在自动充电未参与且仅缺少安全基线时可以正常关闭窗口；系统在存在真实充电责任或明确异常时仍然请求安全处理。

**Blocked by:** 02 - 由设备管理层汇总关闭拦截上下文.

**Status:** done

- [x] 关闭窗口流程通过设备管理层专用判断决定是否拦截关闭窗口。
- [x] 自动充电未授权、没有真实充电责任、仅缺少安全基线时，关闭窗口不再持续请求安全意见。
- [x] 自动已授权但主调度处于 `Idle`，且仅缺少安全基线时，关闭窗口不拦截。
- [x] 自动已授权但主调度处于 `Error`，且仅缺少安全基线时，关闭窗口不拦截。
- [x] 存在手动充电、自动会话未释放、DO0 打开或激活、`Fault` / `Unknown` 时，关闭窗口仍然拦截或要求人工接管。
- [x] UI 层不直接拼接充电状态业务规则，只消费设备管理层的关闭窗口专用判断。
