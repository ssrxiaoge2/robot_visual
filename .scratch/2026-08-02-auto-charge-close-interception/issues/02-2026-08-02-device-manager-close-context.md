# 02 - 由设备管理层汇总关闭拦截上下文

**What to build:** 让设备管理层提供关闭窗口专用的充电安全判断，统一汇总充电控制器状态、自动会话、DO0、应用关闭收尾、主调度参与状态，并把这些事实交给关闭窗口拦截规则。充电控制器原有通用停机判断保持保守，不因为关闭窗口场景而被削弱。

**Blocked by:** 01 - 建立关闭窗口充电拦截规则切面.

**Status:** done

- [x] 设备管理层暴露“是否需要因充电安全拦截关闭窗口”的专用判断。
- [x] 设备管理层能够汇总真实充电责任：活动充电会话、自动会话未安全释放、DO0 打开或激活、应用关闭收尾进行中。
- [x] 设备管理层能够汇总安全事实：控制器是否处于 `Fault` / `Unknown`，以及是否仅缺少安全基线。
- [x] 设备管理层能够识别自动策略是否已参与主调度：自动授权开启，且主调度状态不是 `Idle` 或 `Error`。
- [x] 充电控制器原有通用停机判断不被放宽，手动充电和自动授权安全检查仍然保持保守语义。
- [x] 设备管理层的判断可通过测试证明会调用关闭窗口专用规则，而不是复制一份散落规则。
