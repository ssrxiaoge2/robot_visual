# 01 - 建立关闭窗口充电拦截规则切面

**What to build:** 建立一个可独立验证的关闭窗口充电安全拦截规则，让系统能够区分“仅缺少安全基线但没有真实充电责任”和“设备安全事实未证明”。该规则应证明：没有真实充电责任时不拦截关闭窗口；存在活动充电会话、自动会话未释放、DO0 打开或激活、应用关闭收尾进行中、控制器 `Fault` / `Unknown`、自动策略已参与主调度且缺少安全基线时，仍然拦截关闭窗口。

**Blocked by:** None - can start immediately.

**Status:** done

- [x] 自动策略未参与、控制器仅缺少安全基线、没有真实充电责任时，规则结果为不拦截关闭窗口。
- [x] 自动策略已参与主调度、控制器缺少安全基线时，规则结果为拦截关闭窗口。
- [x] 存在活动充电会话时，规则结果为拦截关闭窗口。
- [x] 自动会话未安全释放时，规则结果为拦截关闭窗口。
- [x] DO0 处于打开或激活时，规则结果为拦截关闭窗口。
- [x] 应用关闭收尾正在进行时，规则结果为拦截关闭窗口。
- [x] 控制器处于 `Fault` / `Unknown` 时，规则结果为拦截关闭窗口。
- [x] 普通只读查询、启动轻量查询、单独 DO0 关闭中且没有真实充电责任时，规则结果为不拦截关闭窗口。
