# 04 - 补齐查询和预检关闭期间的行为保护

**What to build:** 让普通只读查询、启动轻量查询、预检尚未进入 DO0 打开或激活时不会被误判为真实充电责任。关闭意图出现后应取消预检意图，迟到结果不能继续启动 DO0 或充电动作，保证“允许关闭窗口”不会变成后台继续动作。

**Blocked by:** 02 - 由设备管理层汇总关闭拦截上下文.

**Status:** done

- [x] 普通只读查询中，尚未出现 `Fault` / `Unknown` 时，不拦截关闭窗口。
- [x] 启动轻量查询中，尚无真实充电责任时，不拦截关闭窗口。
- [x] 预检尚未进入 DO0 打开或激活时，不拦截关闭窗口。
- [x] 关闭意图出现后，预检意图被取消。
- [x] 预检迟到结果不能继续启动 DO0 或充电动作。
- [x] 单独 DO0 关闭中，且没有真实充电责任时，不拦截关闭窗口。
- [x] 一旦查询或预检揭示控制器 `Fault` / `Unknown`，关闭窗口仍然拦截或要求人工接管。
